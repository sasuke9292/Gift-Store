# 📱 تطبيق متجر گفتي بلس للأندرويد (GiftyPlus Mobile App)

مجلد مخصص بالكامل لتطبيق الأندرويد لمتجر **گِفتي بلس (GiftyPlus)**.

---

## 📦 محتويات المجلد

- **`GiftyPlus.apk`**: ملف تطبيق الأندرويد الجاهز للتثبيت والاستخدام المباشر على أي هاتف يعمل بنظام أندرويد (5.41 MB).
- **`android/`**: مشروع أندرويد ستوديو الأصلي الكامل (Native Android Studio Project) مع إعدادات Gradle، الـ Plugins، والـ AndroidManifest.
- **`capacitor.config.ts`**: ملف إعدادات محرك Capacitor وربط التطبيق بالسيرفر المباشر ومعرّف الحزمة `iq.giftstore.app`.
- **`package.json`**: أوامر تشغيل ومزامنة وبناء التطبيق.

---

## 🚀 كيفية تثبيت التطبيق على هاتفك فوراً

1. انقل ملف `GiftyPlus.apk` إلى هاتفك عبر (واتساب، تيليجرام، كابل USB، أو Google Drive).
2. افتح الملف من الهاتف واضغط **تثبيت (Install)**.
3. إذا ظهر لك تنبيه أمان، اختر **السماح بالتثبيت من هذا المصدر (Allow unknown sources)**.
4. سيظهر تطبيق **گِفتي بلس** فوراً على شاشة هاتفك مع أيقونة الهدية الفاخرة وشاشة البداية الاحترافية.

---

## 🛠️ للمطورين: كيفية فتح المشروع وإعادة البناء

### 1. فتح المشروع في Android Studio
1. افتح برنامج **Android Studio**.
2. اختر **Open** وحدد مجلد `android/` الموجود داخل هذا المجلد.
3. انتظر اكتمال مزامنة Gradle، ثم يمكنك تشغيل التطبيق على المحاكي (Emulator) أو هاتف حقيقي عبر زر **Run ▶**.

### 2. إعادة تجميع وبناء ملف الـ APK عبر السطر البرمجي
من داخل مجلد `android/`:
```powershell
.\gradlew.bat assembleDebug
```
ستجد ملف الـ APK المجمّع في المسار:
`android/app/build/outputs/apk/debug/app-debug.apk`

### 3. مزامنة التغييرات
إذا قمت بتعديل أيقونات أو إعدادات Capacitor:
```bash
npx cap sync android
```
