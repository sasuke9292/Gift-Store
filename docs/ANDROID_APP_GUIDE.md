# 📱 دليل تطبيق الأندرويد الأصلي | Native Android App Guide
### تطبيق متجر گِفتي بلس للأندرويد (Gifty Plus Android Application)

تم بناء وتوليد تطبيق أندرويد أصلي (Native Android App) متكامل ومطابق للمتجر بنسبة 100%، باستخدام **Capacitor 8** مع دعم أحدث إصدارات أندرويد (Android 14, 15, 16 / API 34+).

---

## 🌟 ميزات تطبيق الأندرويد

1. **تطابق كامل وتحديث فوري (Real-Time Live Sync):**
   - التطبيق مرتبط مباشرة بسيرفر الإنتاج السحابي للمتجر (`https://gift-store-rl7i-three.vercel.app`).
   - أي منتج جديد، تعديل سعر، تغيير في السلايدر، أو تحديث في إعدادات المتجر ينعكس فوراً داخل التطبيق دون الحاجة لتحديث التطبيق من Google Play!
2. **تجربة مستخدم أصلية (Native Feel & Experience):**
   - **شريط الحالة (Status Bar):** ملون بلون المتجر الملكي (`#13213c`) مع أيقونات شحن وبيانات واضحة.
   - **الشاشة الترحيبية (Splash Screen):** شاشة افتتاحية ملكية أنيقة مع مؤشر تحميل ذهبي فاخر.
   - **زر الرجوع في الهاتف (Hardware Back Button):** دعم ذكي للرجوع بين الصفحات والسلة دون الخروج المفاجئ من التطبيق.
   - **دعم WhatsApp الأصلي:** عند النقر على "إتمام الطلب عبر واتساب" أو "محادثة المنسق الخاص"، يفتح التطبيق مباشرة تطبيق WhatsApp الرسمي المثبت على هاتف الزبون مع نص الرسالة ورقم المتجر تلقائياً.
   - **رفع الصور والملفات:** إمكانية فتح الكاميرا ومعرض الصور لرفع صور إيصالات الدفع أو صور المنتجات في لوحة التحكم.

## 📁 هيكلية مجلد تطبيق الأندرويد (`android/`)

المشروع مبني بهيكلية **Android Studio Gradle Project** القياسية:
```text
android/
├── app/
│   ├── build.gradle                 # تبعيات وإعدادات بناء الأندرويد ومستوى الـ SDK
│   └── src/main/
│       ├── AndroidManifest.xml      # إذن الإنترنت، شبكات الاتصال، ومخطط حزم الواتساب
│       ├── java/iq/giftstore/app/
│       │   └── MainActivity.java    # نقطة الانطلاق الرئيسية للتطبيق
│       └── res/                     # الموارد، الأيقونات، الألوان، والنصوص
│           ├── values/strings.xml   # اسم التطبيق: گِفتي بلس | Gifty Plus
│           └── mipmap/              # أيقونات التطبيق بدقات الشاشات المختلفة
├── build.gradle                     # إعدادات Gradle الجذرية
├── gradle/wrapper/                  # محرك بناء Gradle التلقائي
├── local.properties                 # مسار الـ Android SDK المحلي
└── capacitor.settings.gradle        # ربط مكونات وإضافات كاباسيتور
```

## 🛠️ كيفية استخراج ملف الـ APK وتثبيته على الهاتف

### الطريقة الأولى: عبر سطر الأوامر (Command Line)
تم إعداد سكريبت البناء الجاهز؛ يمكنك بناء ملف الـ APK بأمر واحد داخل مجلد `android`:
```bash
cd android
.\gradlew.bat assembleDebug
```
عند اكتمال البناء، ستجد ملف الـ APK الجاهز للتثبيت في المسار:
```text
android/app/build/outputs/apk/debug/app-debug.apk
```

---

### الطريقة الثانية: عبر برنامج Android Studio (موصى بها للمطورين)
1. افتح برنامج **Android Studio**.
2. اختر **Open** ثم حدد مجلد `android` الموجود داخل مشروع `Gift-Store`.
3. انتظر ثوانٍ حتى يكتمل فحص الـ Gradle Sync.
4. لتشغيل التطبيق مباشرة على هاتفك أو المحاكي (Emulator):
   - قم بتوصيل هاتفك بالكمبيوتر عبر كابل USB وتفعيل وضع تصحيح الأخطاء (USB Debugging).
   - اضغط على زر **Run (▶)** الأخضر في أعلى شريط الأدوات.
5. لتصدير ملف APK قابل للإرسال:
   - من القائمة العلوية: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
   - سيظهر إشعار في الأسفل يتيح لك فتح مكان الملف (Locate).

## 📲 كيفية تثبيت التطبيق على هاتف العميل أو المدير
1. أرسل ملف `app-debug.apk` إلى الهاتف (عبر WhatsApp، أو Telegram، أو كابل USB، أو Google Drive).
2. انقر على الملف في الهاتف لبدء التثبيت.
3. إذا ظهرت رسالة أمان *"تثبيت التطبيقات من مصادر غير معروفة"*، وافق عليها واختر **سماح / Install Anyway**.
4. سيظهر تطبيق **"گِفتي بلس"** بأيقونته الفاخرة على الشاشة الرئيسية للهاتف وجاهزاً للطلب والتصفح والإدارة فوراً!

---

## 🌐 تثبيت PWA البديل السريع (بدون ملف APK)
يمكن أيضاً لأي مستخدم هاتف أندرويد تثبيت التطبيق مباشرة عبر المتصفح:
1. فتح الرابط: `https://gift-store-rl7i-three.vercel.app`.
2. النقر على القائمة الثلاثية في متصفح Chrome واختيار **"تثبيت التطبيق" (Install App)** أو **"إضافة إلى الشاشة الرئيسية"**.
3. سيتثبت التطبيق فوراً كأنه تطبيق أصلي تماماً بفضل ملف `manifest.json`.
