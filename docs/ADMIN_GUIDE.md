## 1. لوحة المؤشرات والتحليلات

تتيح لك الصفحة الرئيسية للوحة التحكم (`/admin`) مراقبة نبض المتجر بشكل لحظي:
- **إجمالي الإيرادات (Total Revenue):** مجموع المبيعات المكتملة والمؤكدة بالدينار العراقي (د.ع).
- **عدد الطلبات (Total Orders):** إحصائية شاملة للطلبات الجديدة والمجهزة.
- **متوسط قيمة الطلب (Average Order Value):** لقياس سلوك الشراء لدى الزبائن.
- **الرسم البياني للمبيعات (Sales Chart):** مخطط بياني تفاعلي يوضح اتجاهات الإيرادات خلال الأيام والأسابيع السابقة.
- **أحدث الطلبات (Recent Orders):** جدول سريع لآخر الطلبات الواردة مع إمكانية اتخاذ إجراءات مباشرة.

## 2. إدارة المنتجات بالنافذة العائمة

لضمان أقصى درجات السرعة وتفادي إعادة تحميل الصفحات، تم تزويد صفحة المنتجات (`/admin/products`) بـ **بوكس عائم تفاعلي (Floating Modal)** لإضافة وتعديل المنتجات مباشرة:

### إضافة منتج جديد:
1. انقر على زر **"إضافة منتج جديد"** في أعلى الصفحة.
2. ستفتح نافذة منبثقة أنيقة ومقسمة إلى حقول واضحة:
   - **الاسم والوصف:** اسم الهدية الفاخر باللغة العربية مع وصف شاعري وتسويقي جذاب.
   - **الرمز التعريفي (SKU):** رمز فريد للمنتج لضبط وتتبع المخازن (مثال: `GFT-PER-01`).
   - **السعر وسعر التخفيض:** السعر الأساسي بالدينار، مع إمكانية وضع سعر ترويجي (Sale Price) لإظهار شارة الخصم تلقائياً.
   - **القسم والتصنيف:** اختيار القسم المناسب من القائمة المنسدلة.
   - **معرض الصور:** رفع وسحب الصور بجودة عالية (تدعم صور متعددة لكل منتج).
   - **المخزون والشارات:** تحديد الكمية المتاحة وتفعيل شارات "جديد" أو "الأكثر طلباً" أو "منتج مميز".
3. انقر على **"حفظ ونشر المنتج"**، وسيظهر المنتج فوراً في الجدول وفي واجهة المتجر دون مغادرة مكانك!

## 3. دورة حياة الطلبات وإشعارات WhatsApp

تتميز منصة گِفتي بلس بتكامل فريد مع تطبيق **WhatsApp** الذي يمثل وسيلة التواصل المفضلة للمتسوقين في العراق:

### فلترة ومتابعة الطلبات:
في صفحة الطلبات (`/admin/orders`) يمكنك فرز الطلبات حسب الحالة:
- **قيد المراجعة (Pending):** طلبات جديدة وردت من الموقع أو الواتساب بانتظار الاتصال بالزبون.
- **تم التأكيد (Confirmed):** تم الاتصال بالزبون وتثبيت تفاصيل الهدية وتاريخ التوصيل.
- **جاري التجهيز (Processing):** مرحلة التنسيق اليدوي ووضع شريط التغليف الملكي وبطاقة الإهداء.
- **تم الشحن (Shipped):** تسليم الشحنة لشركة التوصيل في بغداد أو المحافظات.
- **مكتمل وتم التسليم (Delivered):** استلام الزبون للهدية وتحصيل المبلغ.
- **ملغى (Cancelled) أو مرتجع (Returned).**

### 📲 ميزة إشعار WhatsApp بنقرة واحدة (1-Click Notification):
بجانب كل طلب في قائمة الطلبات أو داخل صفحة التفاصيل، ستجد زراً ذكياً **"إشعار واتساب"**:
1. عند تغيير حالة الطلب (مثلاً من "جاري التجهيز" إلى "تم الشحن").
2. انقر على زر **"إرسال إشعار للزبون"**.
3. يقوم النظام تلقائياً بتنسيق رقم هاتف العميل إلى الصيغة الدولية العراقية (`9647xxxxxxxxx`).
4. يتم توليد رسالة فخمة مهنية تبدأ باسم الزبون، تتضمن رقم طلبه، وحالته الحالية، وملاحظات التتبع مع عبارات ترحيبية راقية تعزز ثقة العميل بالمتجر.

## 4. محرك إعدادات المتجر الشامل

تعتمد صفحة الإعدادات (`/admin/settings`) على معمارية **Two-Column Master Layout** التي تجمع 13 تبويباً تخصصياً داخل 4 محاور رئيسية منظمة:

```text
┌────────────────────────┬──────────────────────────────────────────┐
│ أقسام الإعدادات المنظمة │ نافذة التعديل والتخصيص التفاعلية         │
├────────────────────────┼──────────────────────────────────────────┤
│ 🎨 واجهة المتجر والمظهر │ • الهوية والشعار والعملة                 │
│                        │ • استوديو شرائح السلايدر التفاعلي        │
│                        │ • دليل الإهداء وبطاقات المهدى له         │
│                        │ • ترويسة المتجر وشريط الإعلانات          │
│                        │ • تبويبات القائمة والتنقل                │
│                        │ • بانر الفوتر والمزايا الأربعة           │
├────────────────────────┼──────────────────────────────────────────┤
│ 📦 المبيعات والشحن     │ • حد الشحن المجاني (مثال: 100,000 د.ع)   │
│                        │ • أجور شحن بغداد وشحن المحافظات          │
│                        │ • بوابات الدفع (الدفع نقداً، زين كاش، FIB) │
├────────────────────────┼──────────────────────────────────────────┤
│ 💬 التواصل وقنوات البيع│ • رقم الواتساب الرسمي وقوالب رسائل الطلب │
│                        │ • أرقام الهاتف وأوقات العمل الرسمية      │
│                        │ • روابط صفحات التواصل الاجتماعي          │
├────────────────────────┼──────────────────────────────────────────┤
│ ⚙️ محركات البحث والنظام │ • معاينة بحث Google المباشرة (SERP)      │
│                        │ • الكلمات الدلالية المفتاحية (Keywords)  │
│                        │ • إشعارات الطلبات وحد نقص المخزون        │
└────────────────────────┴──────────────────────────────────────────┘
```

### 🌟 أبرز مميزات قسم السيو والنظام:
- **معاينة بحث Google الحية (Live SERP Preview):** يظهر لك تماماً كيف سيبدو متجرك في شاشة البحث مع عنوان باللون الأزرق ومسار الرابط ووصف تعريفي جذاب.
- **عدادات الطول المثالي:** مؤشر ذكي يوضح إن كان طول العنوان (30 - 65 حرفاً) أو الوصف (60 - 160 حرفاً) مثالياً لعدم اقتطاعه في Google.
- **سحابة الكلمات المفتاحية:** كتابة الكلمات المفتاحية مفصولة بفاصلة ليعرضها النظام على شكل وسوم أنيقة فوراً.

## 5. استوديو شرائح السلايدر التفاعلي

من خلال صفحة (`/admin/hero-slides`) أو تبويب "شرائح السلايدر" في الإعدادات:
- إضافة شرائح جديدة وتعيين صورة البانر (نسبة عرض موصى بها: `16:9` أو `21:9`).
- كتابة العنوان الرئيسي والعنوان الفرعي وشارة العرض (مثال: "عرض حصري").
- تحديد رابط الانتقال عند النقر (مثلاً: `/category/women` أو `/shop`).
- ترتيب الشرائح للأعلى أو الأسفل وتفعيل أو إيقاف أي شريحة بنقرة زر دون حذفها.

## 6. إدارة المستخدمين والأدوار

تتيح صفحة (`/admin/users`) توزيع المهام الإدارية بأمان:
- **المدير العام (SUPER_ADMIN):** تحكم مطلق في جميع الإعدادات وحذف المستخدمين والبيانات الحساسة.
- **مدير المتجر (ADMIN / MANAGER):** إدارة المنتجات، التصنيفات، وتعديل إعدادات المتجر والطلبات.
- **فريق المبيعات والدعم (SALES / SUPPORT):** الوصول لقائمة الطلبات وإرسال إشعارات الواتساب ومتابعة الزبائن.
- **أمين المستودع (WAREHOUSE):** مراقبة المخزون وتحديث كميات المنتجات وتجهيز الشحنات.
