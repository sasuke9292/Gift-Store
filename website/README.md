# 🌐 موقع متجر گفتي بلس (Gift-Store Web Application)

مجلد مخصص بالكامل لموقع الويب والمتجر الإلكتروني المبني بـ **Next.js 16** و **Prisma** و **PostgreSQL** و **TailwindCSS**.

---

## 📦 محتويات المجلد

- **`src/`**: يحتوي على مكونات الواجهة (Components)، الصفحات (App Router)، وتنسيقات CSS، ونظام المصادقة.
- **`public/`**: الملفات الثابتة والوسائط والصور وأيقونات PWA والـ manifest.json.
- **`prisma/`**: مخطط قاعدة البيانات PostgreSQL ونصوص البيانات الأولية (Seed script).
- **`next.config.ts`**: إعدادات إطار العمل Next.js.
- **`package.json`**: حزم الاعتماد وأوامر التشغيل والبناء.

---

## 🚀 أوامر التشغيل السريع

من داخل مجلد `website/`:

```bash
# تشغيل السيرفر المحلي للتطوير
npm run dev

# بناء الموقع للإنتاج
npm run build

# تشغيل النسخة الإنتاجية
npm run start
```
